# 🌾 Soil & Crop Information Portal

A web-based application designed to display essential information about various soil types and corresponding suitable crops and seed distributors. Built to help users (farmers, agricultural enthusiasts, etc.) make informed decisions about crop selection based on soil characteristics.

---

## 📖 Problem Statement

Soil plays a vital role in agriculture. Each soil type has distinct traits and supports specific crops. This application helps users understand which crops grow best in which types of soil by providing:
- Soil type information
- Characteristics of soil
- Suitable crop and seed distributor details

The **Admin** will be responsible for adding and managing this data with support from soil and crop experts.

---

## 🧩 System Modules

### 👤 Admin
- Admin Login
- Post Soil Details
- Post Distributor Details

### 🙋 User
- User Register
- User Login
- View Soil Details
- View Distributor Details
